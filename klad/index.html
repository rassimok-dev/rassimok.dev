BLOCKED. This text is static markup. If it is still here, the module did not execute and the scoped CSP is not working.

Why

Cloudflare Pages merges matching _headers rules rather than letting the specific one win, and joins duplicate header values with a comma. Two comma-joined CSP values are enforced as an intersection, so the apex default-src 'none' would still block this script. The fix under test is removing the inherited header with a bang prefix before setting the replacement.
