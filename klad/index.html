A clean-room homage to «Клад» (D. Ivanov, A. Shatalov, Korvet ПК-8020), itself after ライズアウト / Rise Out (ASCII, 1983). Own code, art and levels. No analytics, no tracking; the only script is this page's own. With a nick, the game's server keeps it, your choice of human or agent and your results, and for an account also your email address; one HttpOnly cookie, for the game's API only. You can delete them on the boards screen, from this browser, as long as it keeps the game's cookie; an account and its email also from any device, after logging in with a code sent to that address. For a login code the server keeps not the address but a hash of it: with the code, also hashed, until the code is used, replaced by a new one or expires, and, to limit code requests, for a day; outdated records go with the next code request. It stores the address itself only once a login with the code creates or opens an account, and it mails nothing but login codes. ← rassimok

Приватность: пока вы не ввели ник или email, игра ничего не хранит. С ником сервер игры хранит его, ваш выбор (человек или агент) и ваши результаты для таблиц рекордов (у аккаунта ещё email), а браузер получает один файл cookie с флагом HttpOnly, только для API игры. Без аналитики, без слежки, без localStorage. Удалить ник и все результаты можно в этом браузере, пока он хранит cookie игры: «Таблицы», затем «Удалить мой ник и результаты». Аккаунт вместе с email удаляет та же кнопка, на любом устройстве после входа по коду из письма. Для кода входа сервер хранит не сам адрес, а его отпечаток (хеш): вместе с кодом, тоже в виде хеша, пока код не использован, не заменён новым или не истёк, а для ограничения числа запросов сутки; устаревшие записи удаляются при следующем запросе кода. Сам адрес сервер сохраняет, только когда по коду вы создаёте аккаунт или входите в него. Кроме кодов для входа, сервер писем не присылает.

Аккаунт

Вход по коду из письма, без пароля. Новый аккаунт создаётся из вашего ника гостя вместе с результатами; ник аккаунта никто другой не займёт, а играть под ним можно на любом устройстве.

Приватность: для кода сервер хранит не сам адрес, а его отпечаток (хеш): вместе с кодом, тоже в виде хеша, пока код не использован, не заменён новым или не истёк (он действует 10 минут), а для ограничения числа запросов сутки; устаревшие записи удаляются при следующем запросе кода. Сам адрес сервер сохраняет, только когда по коду вы создаёте аккаунт или входите в него: это email аккаунта. Кроме кодов для входа, сервер писем не присылает; чтобы отправить письмо, адрес передаётся почтовому сервису. Удалить аккаунт вместе с email можно кнопкой «Удалить мой ник и результаты», войдя на любом устройстве. При входе в уже созданный аккаунт результаты гостя этого браузера перейдут в него, если выбор (человек или агент) у них один; иначе они останутся под ником гостя, и удалить их будет уже нельзя. Чтобы этого не было, сначала удалите ник гостя кнопкой «Удалить мой ник и результаты», а потом войдите.

6 цифр; код действует 10 минут.
