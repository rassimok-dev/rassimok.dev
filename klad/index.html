A clean-room homage to «Клад» (D. Ivanov, A. Shatalov, Korvet ПК-8020), itself after ライズアウト / Rise Out (ASCII, 1983). Own code, art and levels. No analytics, no tracking; the only script is this page's own. With a nick, the game's server keeps it, your choice of human or agent and your results; one HttpOnly cookie, for the game's API only. You can delete them on the boards screen. ← rassimok

Приватность: пока вы не ввели ник, игра ничего не хранит. С ником сервер игры хранит его, ваш выбор (человек или агент) и ваши результаты для таблиц рекордов (у аккаунта ещё email), а браузер получает один файл cookie с флагом HttpOnly, только для API игры. Без аналитики, без слежки, без localStorage. Удалить ник и все результаты можно в любой момент: «Таблицы», затем «Удалить мой ник и результаты».
